## list.py 优化：翻页筛选校验

- 用 `clickParam.args.filterField` 字段（API 数据自带）验证每页筛选是否生效，不再依赖 DOM 检测
- `filterField` 格式：`{"publishDays":"7","quickFilter":"filterPersonal"}` → 对应 7天内 + 个人闲置
- 每页收集筛选状态并在结束后打印汇总报告
- 移除了 DOM-based 的 `ensure_filters_active` 函数（CSS class 检测不可靠，会误报）

测试结果：2 页都验证通过，"个人闲置" + "7天内"筛选正常保持。
